أريد منك إنشاء موقع ويب ثابت (Static Website) احترافي ومتجاوب لأكاديميتي مفتاح العلوم لتعليم كلام الحي القيوم.
هذا الموقع سيكون الموقع التعريفي والتسجيلي المؤقت للأكاديمية لحين إطلاق الموقع الرسمي المتكامل قريبًا بإذن الله.

أولًا: طبيعة المشروع وتقنياته
1. إنشاء موقع ويب ثابت باستخدام HTML وـ CSS وـ JavaScript، دون الحاجة إلى Backend أو قاعدة بيانات.
2. يجب أن يكون الموقع متوافقًا تمامًا مع GitHub Pages.
3. سأضع المشروع في مستودع GitHub مستقل تمامًا عن مستودعات مشروعاتي الأخرى.
4. يجب أن تعمل جميع الروابط والتنقلات والملفات بصورة صحيحة عند استضافة الموقع داخل مستودع GitHub Pages، مع مراعاة أن رابط الموقع قد يتضمن اسم المستودع بعد اسم النطاق.
5. عدم استخدام مسارات مطلقة تؤدي إلى تعطل الملفات عند النشر داخل مستودع فرعي.
6. عدم استخدام خدمات مدفوعة أو مفاتيح API أو متغيرات بيئة أو خوادم خارجية.
7. يُمنع تمامًا استخدام المكتبات والأطر الخارجية، ويجب الاعتماد على JavaScript وـ CSS الأصليين.
8. تنظيم الملفات بطريقة واضحة وقابلة للصيانة والتطوير مستقبلًا.

ثانيًا: الهوية البصرية والتصميم
أنشئ تصميمًا يعكس هوية أكاديمية متخصصة في تعليم القرآن الكريم والتجويد والقراءات.
المطلوب:
- تصميم إسلامي عصري وأنيق وهادئ.
- ألوان متناسقة توحي بالوقار والعلم والطمأنينة.
- استخدام الخطوط العربية المناسبة والواضحة.
- دعم اللغة العربية واتجاه الكتابة من اليمين إلى اليسار RTL في جميع الصفحات.
- تصميم متجاوب مع الهواتف والأجهزة اللوحية والحواسيب.
- واجهة بسيطة ومنظمة وسهلة الاستخدام.
- استخدام تأثيرات حركية خفيفة عند الحاجة، دون المبالغة فيها أو التأثير على الأداء وإمكانية الوصول.
- عدم وضع عناصر زخرفية تعيق التنقل أو تجعل قراءة المحتوى صعبة.

ثالثًا: الصفحات المطلوبة
يتكون الموقع من ثلاث صفحات رئيسية:
1. الصفحة الرئيسية (index.html) بعنوان ومقدمة رئيسية وتعريفًا بالأكاديمية
يجب أن تتضمن الصفحة:
- قسمًا رئيسيًّا ترحيبيًا يعرض اسم الأكاديمية ورسالتها.
- نبذة تعريفية عن الأكاديمية وأهدافها.
- توضيح أن الأكاديمية تهتم بتعليم القرآن الكريم والتجويد والقراءات.
- توضيح أن الدراسة تتم عن بُعد.
- إبراز أن التعليم يستهدف مختلف الأعمار والمستويات.
- قسمًا للتعريف بالخدمات التعليمية دون اختراع برامج أو شهادات أو مزايا غير معتمدة.
- قسمًا يوضح خطوات الالتحاق بالأكاديمية بصورة مختصرة.
- زرًا واضحًا بعنوان «سجّل الآن» ينقل المستخدم إلى صفحة التسجيل.
- روابط متابعة الأكاديمية، بما فيها صفحة فيسبوك وقناة واتساب، مع وضع روابط قابلة للتعديل في ملف إعدادات مركزي.
- تذييلًا يحتوي على اسم الأكاديمية وروابط الصفحات وحقوق الطبع والنشر.
احرص على أن تكون الصفحة غنية بالمعلومات المفيدة، لكن دون إطالة غير ضرورية أو تكرار.

2. صفحة التسجيل (register.html) بعنوان ومقدمة
أنشئ نموذج تسجيل احترافيًّا يتضمن الحقول التالية بالترتيب:
1. الاسم الكامل.
2. النوع: ذكر أو أنثى.
3. تاريخ الميلاد، مع التشديد على ضرورة إدخاله بشكل صحيح، أو تعديله قبل إرسال رسالة التسجيل على واتساب.
4. الجنسية.
5. الدولة.
6. العنوان.
7. رقم الهاتف، مع دعم إدخال رمز الدولة، والتشديد على ضرورة إدخاله باللغة الإنجليزية.
8. البريد الإلكتروني.
9. عدد الأجزاء المحفوظة من القرآن الكريم.
10. سبب الرغبة في الالتحاق بالأكاديمية.
11. كيف تعرفت على الأكاديمية؟ (مكان العلم بنا).
12. ملاحظات إضافية.
متطلبات النموذج:
- استخدام عناصر HTML المناسبة لكل نوع من البيانات.
- وضع تسمية واضحة ومستقلة لكل حقل.
- تمييز الحقول المطلوبة والاختيارية بوضوح.
- استخدام التحقق من صحة البيانات قبل تجهيز رسالة واتساب.
- السماح بكتابة النصوص الطويلة في الحقول المناسبة.
- تقديم رسائل خطأ عربية واضحة عند وجود بيانات ناقصة أو غير صحيحة.
- الحفاظ على البيانات التي أدخلها المستخدم عند ظهور خطأ حتى لا يضطر إلى إعادة كتابتها.
- تنظيم النموذج في أقسام منطقية لتسهيل تعبئته.
- عدم إرسال البيانات إلى أي خادم أو تخزينها في قاعدة بيانات.

3. صفحة اتصل بنا (contact.html) بعنوان
تتضمن الصفحة:
- مقدمة ترحيبية تشجع الزائر على التواصل والاستفسار.
- نموذجًا يحتوي على:
  1. الاسم.
  2. الرسالة.
- زرًّا بعنوان «إرسال عبر واتساب».

رابعًا: آلية الإرسال عبر واتساب
هذه من أهم وظائف الموقع، ويجب تنفيذها بصورة صحيحة في صفحتَي التسجيل واتصل بنا.
لا أريد إرسال البيانات إلى خادم أو قاعدة بيانات، وإنما أريد تجهيز رسالة واتساب تلقائيًا من البيانات التي أدخلها المستخدم.
آلية العمل:
1. يملأ المستخدم النموذج.
2. يتحقق JavaScript من صحة الحقول المطلوبة.
3. قبل تنفيذ الإرسال، يجب عرض تنبيه واضح للمستخدم بأن بياناته ستُجهَّز في رسالة، وسيتم فتح تطبيق واتساب أو واتساب ويب لإرسالها إلى الأكاديمية.
4. عند ضغط المستخدم على زر الإرسال، تُنشأ رسالة نصية منسقة باللغة العربية تحتوي على البيانات المدخلة.
5. يتم ترميز الرسالة باستخدام encodeURIComponent.
6. يتم فتح رابط واتساب باستخدام الصيغة: https://wa.me/INTERNATIONAL_PHONE_NUMBER?text=ENCODED_MESSAGE
7. يجب وضع رقم واتساب الأكاديمية في ملف إعدادات مركزي يسهل تعديله، مع توضيح أن الرقم يجب أن يكون بالصيغة الدولية دون علامة + أو مسافات.
8. لا تضع رقمًا افتراضيًا مختلقًا.

خامسًا: تأكيد الإرسال
هذه نقطة مهمة جدًّا:
- يجب إخبار المستخدم قبل الضغط على زر الإرسال بأن المعلومات ستُرسل عبر واتساب، وأن الضغط على الزر سيفتح واتساب مع الرسالة المجهزة.
- بعد الضغط على الزر والتحقق من البيانات، اعرض تأكيدًا واضحًا بأن واتساب سيُفتح لإتمام الإرسال.
- لا تعرض رسالة توهم المستخدم بأن الرسالة أُرسلت بالفعل؛ لأن الإرسال النهائي يتطلب ضغط المستخدم على زر الإرسال داخل واتساب.
- إذا تعذر فتح واتساب، أظهر رسالة مفهومة مع إمكانية نسخ محتوى الرسالة إلى الحافظة.

سادسًا: إمكانية الوصول (Accessibility)
هذه نقطة أساسية وليست تحسينًا اختياريًّا.
يجب تصميم الموقع ليكون قابلًا للاستخدام الكامل بواسطة المكفوفين ومستخدمي قارئات الشاشة.
التزم بالآتي:
1. استخدام HTML دلالي صحيح Semantic HTML.
2. استخدام العناوين بترتيب هرمي منطقي دون تجاوز المستويات.
3. ربط كل حقل في النماذج بتسمية Label حقيقية.
4. عدم الاعتماد على الألوان أو الأيقونات وحدها لتوضيح حالة العنصر.
5. جعل جميع عناصر الموقع قابلة للتشغيل باستخدام لوحة المفاتيح.
6. توفير مؤشر تركيز واضح Focus Indicator.
7. دعم التنقل المنطقي باستخدام مفتاح Tab وShift+Tab.
8. استخدام ARIA عند الحاجة فقط، وعدم استخدامه بديلًا عن HTML الدلالي.
9. استخدام aria-live لإعلان رسائل النجاح والأخطاء والتأكيدات لقارئات الشاشة.
10. عدم الاعتماد على النوافذ أو العناصر المرئية التي لا يمكن لقارئ الشاشة الوصول إليها.
11. توفير نصوص بديلة مناسبة للصور المهمة.
12. تجنب العناصر التفاعلية المصممة باستخدام div أو span دون توفير السلوك الدلالي الكامل.
13. التأكد من أن القوائم وأزرار التنقل والنماذج تعمل بصورة صحيحة مع NVDA.
14. التأكد من أن ترتيب التركيز منطقي، وأن الانتقال إلى محتوى الصفحة الرئيسية ممكن بسهولة.
15. دعم تكبير النصوص دون فقدان المحتوى أو الوظائف.
استهدف الامتثال لمعيار WCAG 2.2 AA قدر الإمكان.

سابعًا: تحسين محركات البحث والأداء
- إضافة عنوان ووصف مناسبين لكل صفحة.
- إضافة بيانات اللغة العربية واتجاه RTL.
- إضافة Open Graph للمعاينة عند مشاركة الموقع.
- استخدام أسماء ملفات واضحة.
- تحسين سرعة التحميل.
- ضغط الصور وعدم تحميل ملفات ضخمة دون داعٍ.
- تجنب الاعتماد على JavaScript في عرض المحتوى الأساسي.
- إضافة صفحة 404 مناسبة إن أمكن.

تاسعًا: تعليمات التنفيذ والاختبار
أريد تنفيذ المشروع فعليًّا داخل المستودع، وليس مجرد تقديم أمثلة أو شرح نظري.
اتبع الخطوات التالية:
1. افحص ملفات المستودع الحالي قبل البدء.
2. أنشئ ملفات المشروع كاملة.
3. نفّذ الصفحات الثلاث بتصميم موحد.
4. اربط الصفحات ببعضها بصورة صحيحة.
5. نفّذ وظائف نماذج التسجيل والتواصل والإرسال عبر واتساب.
6. اختبر صحة التحقق من الحقول وترميز الرسائل العربية.
7. اختبر الروابط والمسارات مع مراعاة GitHub Pages.
8. راجع إمكانية الوصول باستخدام لوحة المفاتيح وقارئات الشاشة قدر الإمكان.
9. أصلح الأخطاء التي تظهر أثناء الاختبار.
10. لا تعتبر المشروع مكتملًا بمجرد إنشاء الملفات؛ يجب التأكد من أن الوظائف الأساسية تعمل.

عاشرًا: النشر على GitHub Pages
أريد أن يكون المشروع جاهزًا للنشر مباشرة على GitHub Pages.
أضف إلى README.md تعليمات عربية واضحة تتضمن:
- وصف المشروع.
- هيكل الملفات.
- كيفية تعديل بيانات الأكاديمية.
- كيفية تعديل رقم واتساب.
- كيفية تعديل روابط التواصل الاجتماعي.
- كيفية تشغيل الموقع محليًا.
- كيفية نشره على GitHub Pages من إعدادات المستودع.
- كيفية اختبار الموقع بعد النشر.
إذا احتاج المشروع إلى بيانات لم أقدمها، مثل رقم واتساب أو روابط صفحات التواصل، فلا تخترعها؛ ضع قيمًا فارغة أو قيمًا إرشادية واضحة، واجمعها في ملف إعدادات مركزي.

الحادي عشر: معايير الجودة النهائية
أريد موقعًا:
- احترافيًّا يعكس مكانة الأكاديمية ورسالتها.
- سهل الاستخدام لجميع الفئات.
- متوافقًا مع المكفوفين وقارئات الشاشة.
- سريعًا وخفيفًا.
- آمنًا ويحافظ على خصوصية بيانات المستخدمين.
- يعمل دون Backend.
- جاهزًا للنشر على GitHub Pages.
- سهل التعديل والتطوير لاحقًا.

ابدأ بتنفيذ المشروع، ثم أعطني تقريرًا نهائيًا يوضح الملفات التي أنشأتها، والوظائف التي نفذتها، والاختبارات التي أجريتها، وأي بيانات لا تزال بحاجة إلى إدخالها مني.
